AOT Analysis & Blutter Workflow Toolkit

Complete end-to-end pipeline: Extract target binaries → Run Blutter analysis on workstation → Convert & upload symbols → Dynamic hooking.

1
Select Target App & Download libapp.so
Extracts ARM64 AOT snapshot binary directly from the device
Select an installed app from your device or specify a package name. deFlutter uses root access to locate the APK, extract libapp.so, and stream it to your browser—no manual adb commands required.
2
Download blutter2symbols.py & Run Blutter on Workstation
Reverse-engineers Dart AOT objects and formats function offsets
Run Blutter on your workstation against the downloaded libapp.so, then use our companion Python script to generate a structured symbols.json.
Script Dependencies
✓ Python 3.6+ ✓ Zero pip packages (100% portable) ✓ Standard Library only: os, sys, re, json, time
🐍 Download blutter2symbols.py (Python Script)
Run in your workstation terminal:
# 1. Reverse engineer downloaded libapp.so with Blutter
python blutter.py path/to/libapp.so blutter_out/

# 2. Extract structured symbols JSON using the downloaded script
python blutter2symbols.py blutter_out/ -o symbols.json
3
Upload symbols.json & Activate Live Hooking
Imports class hierarchies, field offsets, and function signatures
Upload the generated symbols.json for target (select above). This maps raw function offsets to Dart methods, decodes Class IDs (CIDs), and enables one-click Dobby hooking.
